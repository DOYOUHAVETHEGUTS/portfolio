StudyForge v1 Re-creation

The original desktop prototype

Before the web app, StudyForge was a local Tkinter window that did one thing: point it at a textbook, make one summarization call per chapter, and email the result. This is a faithful re-creation of that flow, including the failure modes that drove the rewrite — run it and watch where it breaks.

Ready. Chapter detection uses bookmarks titled "Chapter N".

What this version got wrong. Every behavior above is real: chapter detection that only matched literal "Chapter N" bookmarks and silently found nothing in other books; a single one-shot summarization call with no grounding check; no retries; and an email path that failed on TLS certificate handling while the queue advanced anyway, so a failed send looked like a completed one. Those four failures are what v2 and v3 were built to fix.
